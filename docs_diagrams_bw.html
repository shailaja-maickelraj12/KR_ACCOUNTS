DOUBLE-ENTRY VOUCHER PROCESSING WORKFLOW

1. VOUCHER SELECTION & SERIAL NUMBERING
Select Voucher Type (JV / Cash Payment / Bank Payment / Contra / Debit & Credit Note)
Auto-generate financial serial number (e.g. JV-00001, CP-00001) & set Voucher Date
↓
2. LINE-ITEM INPUT & OPTIONAL TAX CALCULATION
Add Account Heads, Debit / Credit amounts, and item-level narrations
Lookup TDS Master for section rate & automatically compute TDS / Surcharge lines
↓
3. DOUBLE-ENTRY MATHEMATICAL VALIDATION
Formula Check: Σ Total Debit == Σ Total Credit (and Total > 0)
• If Unbalanced: Display discrepancy difference & block submission.
• If Balanced: Package payload & proceed to atomic API transaction.
↓
4. ATOMIC DATABASE PERSISTENCE (POST /ams/vouchers)
Upsert Voucher Header in Voucher table & bulk insert items in VoucherItem table
Append audit trail entry to AuditLog table inside ACID transaction
↓
5. FINANCIAL LEDGER PROPAGATION & TALLY SYNC
Post Debits & Credits to General Ledger and update Cash / Bank balances
Recalculate Trial Balance, Profit & Loss, and Balance Sheet in real-time
(Optional) Generate Tally Prime XML envelope and transmit to HTTP Port 9000
